# Water Quality Monitoring Dataset - Variable Dictionary

This document describes the variables used in the water quality monitoring dataset.

---

# General Information

| Variable                             | Description                              |
| ------------------------------------ | ---------------------------------------- |
| Fecha monitoreo                      | Date when the water sample was collected |
| Hora Monitoreo                       | Time when the sample was collected       |
| Nro del Informe del Ensayo análitico | Laboratory analytical report identifier  |

---

| Nitratos-N                           | mg/L         | Nitrate nitrogen concentration                  |

# Parámetros Microbiológicos y Parasitológicos

These variables describe microbiological contamination indicators.

| Variable                   | Unit      | Description                            |
| -------------------------- | --------- | -------------------------------------- |
| Coliformes Termotolerantes | NMP/100ml | Thermotolerant coliform bacteria count |
| Coliformes Totales         | NMP/100ml | Total coliform bacteria count          |

---

# Notes

* `mg/L` = milligrams per liter
* `µS/cm` = microsiemens per centimeter
* `L/s` = liters per second
* `NMP/100ml` = Most Probable Number per 100 milliliters
* Values beginning with `<` indicate measurements below the laboratory detection limit.
* `----` may indicate missing or unavailable data.
